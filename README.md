## ■ こんな「画面とにらめっこの目視突合」、毎月何時間ドブに捨てていませんか？

- **数万行のデータで「どこが変わったか」を探す恐怖**: 価格マスターや顧客リストで、新旧データを2画面に並べて目視比較し、眼精疲労と「見落としたら事故になる」プレッシャーに怯える日々。
- **VLOOKUPや条件付き書式での突合に疲弊する**: 関数を組んだり条件付き書式を設定するだけで30分以上かかり、計算が重すぎてExcelが「応答なし」でフリーズしてしまう。
- **行が1行ズレただけで比較が全滅する**: 途中で行が1行追加・削除されていたり、並び順が変わっていると、単純なセル比較では以降の行がすべてズレて誤判定の嵐になる。
- **上司や監査向けの「変更履歴レポート」作成が面倒**: 「今回どこが変更になったの？」と聞かれ、変更箇所を手作業でピックアップして別シートにまとめる不毛な二度手間。

経理、財務、購買、マスターデータ管理において、データの更新差分チェックは絶対にミスの許されない最重要業務です。  
しかし、**本来分析や確認、判断に注ぐべき貴重な集中力を、「セルを目視で探すだけの単純作業」に何時間も奪われ続ける必要はありません。**

「ExcelDiffHighlighter GUI」は、ビジネス現場の突合ストレスと見落としリスクをゼロにするために生まれた、完全実務特化型のポータブルソフトウェアです。

## ■ なぜ、他の方法ではなく「ExcelDiffHighlighter」なのか？（4つの圧倒的理由）

### 1. 数学的一致比較による「100%の差分検出精度（先頭ゼロも完全保持）」
AIのあいまいな推測に頼らず、数学的な完全一致・等価比較のみを採用。1文字の変更も100%漏れなく検出します。  
また、全セルデータを文字列型として厳格に処理するため、商品コードの先頭ゼロ（`00123`）が勝手に数値化されて消えたり、日付形式が勝手に変わって誤検出される心配はゼロです。

### 2. どこが変わったか一瞬でわかる「差分専用レポートブック（新旧上下対比）」
膨大な元データの中から差分箇所を探す手間をゼロにするため、**変更があった箇所のみを凝縮した専用レポートブック（`diff_summary_report.xlsx`）**を自動生成：
- **サマリーカード**: 変更〇件、追加〇件、削除〇件が一目で把握でき、上司や監査への提出資料にそのまま使えます。
- **差分レコード新旧対比**: 変更のあった行だけを抽出し、**旧データ行と新データ行を上下2行ペアで並列表示**。変更されたセルのみ薄黄でピンポイント着色されるため、前後の文脈が一目でわかります。

### 3. 表構造をまるごと残す「高視認性パステル3色ハイライトExcel」
元データ全体の表構造を維持したい用途向けに、全行を収録したハイライトExcel（`diff_highlighted_result.xlsx`）も同時出力：
- **追加行（新データのみ）**: 行全体をソフトミントグリーン（緑）でハイライト
- **削除行（旧データのみ）**: 専用シートにソフトローズ（赤）でハイライト出力
- **変更セル（値が変わった箇所）**: 該当セルのみをソフトイエロー（黄）でピンポイント着色 ＋ ワイドコメントで「旧値 ➔ 新値」を明瞭表示

### 4. 実務の表記ゆれ自動吸収 ＆ 完全オフラインの最高セキュリティ
全角半角の違い（`ＡＢＣ` / `ABC`）、前後の余計な空白、金額のカンマ（`1,000` / `1000`）、日付書式の違い（`2024/09/01` / `2024-09-01`）を自動で同一視するスマート判定機能を搭載。  
さらに完全オフライン動作のため、財務諸表や顧客台帳、社外秘の原価データも情報漏洩リスクゼロで安全に処理できます。

## ■ 作業時間は「半日」から「3秒」へ（使い方3ステップ）

1. **起動する**: フォルダ内の `ExcelDiffHighlighter.vbs` をダブルクリックします。
2. **放り込む**: 画面の案内に従って「旧ファイル」と「新ファイル」をそれぞれドラッグ＆ドロップします。
3. **ボタンを押す**: **「差分ハイライト＆変更ログ生成を実行」** をクリック。
   - 画面上に差分サマリーとプレビュー表が即座に表示されます。
   - **「📦 差分結果を一括保存 (ZIP)」** を押せば、着色済みハイライトExcelと差分専用対比レポートブックが一瞬で手に入ります。
